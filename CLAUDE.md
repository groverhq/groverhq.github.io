## What this repo is
GroverHQ agency site at https://groverhq.com: Astro 6 + Tailwind 4 static site on GitHub Pages (repo groverhq/groverhq.github.io). Work happens on branches and PRs into main (e.g. "Merge pull request #22 from groverhq/add_parvesh_review"). `dist/` is ignored. Commands: `npm run dev`, `npm run build`, `npm run check`.
Config lives in `src/config.ts` (site, contact, social); layout/SEO/JSON-LD in `src/layouts/BaseLayout.astro`; sitemap files in `public/` plus @astrojs/sitemap.
